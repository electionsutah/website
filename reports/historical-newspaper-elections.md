# Historical newspaper election import

The four contemporary Deseret News articles used for Alton also supply the imported 1989, 1991, 1993 and 1995 returns across Utah. See [the linked HTML report](historical-newspaper-elections.html) for all places, candidate profiles, offices, tallies, source links and unresolved entries. Its body uses the required `3rem` margin.

The manifest contains 1,603 published contest entries: 1,540 candidate contests and 63 ballot questions. Its 4,918 named candidate entries include two repeated entries in the same office/year/place; 4,916 distinct appearances are retained as filings. The existing Alton import supplies 21 of those filings; `src/data/newspaper-candidates.json` adds 4,895. Repeated source contest entries remain visible with notes. Names are retained as published. Winners and tie resolutions are not inferred from ranking.

Sixteen absent, illegible or placeholder vote tallies remain null, displayed as “—”. Known-vote subtotals exclude these values and unnamed write-in recipients. The truncated Enterprise 1991 entry lacks its office and full candidate roster; Leeds 1991 has an election-suspension narrative rather than a roster. These limitations remain in the report. School-district measures appear under their county with the district’s name. Historical Hiawatha, Sunnyside and Ophir pages describe historical records without asserting present municipal status.

Run `npm run refresh:newspaper` to rebuild candidate/result data and the HTML report from the committed factual manifest. Run `npm run check:municipal-results` to check all rendered tables, candidate links, vote reconciliation and important extraction edge cases. To re-extract the original articles, first download their public HTML to the ignored `.firecrawl/municipal-{year}.html` files and export the current entity place map to `.firecrawl/place-map.json`, then run `python3 scripts/import-newspaper-elections.py --extract --import`. Raw article HTML is intentionally not committed.

Coverage follows the published articles, not all present-day municipalities. The 1991 source explicitly excludes Salt Lake County. Missing jurisdictions, offices and years remain coverage gaps; source absence does not establish that no election occurred. The separate municipal coverage audit measures coverage against the current 257-municipality reference, excluding historical municipalities no longer in that reference.
