Values retained deliberately

  • Fluid display headings, breakpoints, border thicknesses, icon geometry, chart dimensions, and component-specific date typography do not automatically belong to the spacing or text scales.
  • Party identity colors in entities.ts and the exported palette in results.ts remain literal values. The result palette explicitly documents its relationship to CSS tokens. A future shared palette should supply concrete colors to data and canvas/map consumers as well as CSS; CSS variable strings are not a safe drop-in replacement.
  • One-off large section spacing and layout dimensions remain local. Consolidate repeated semantic roles only when the components should evolve together.
